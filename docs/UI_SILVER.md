# 银白石墨后台界面

采用已确认的银白石墨设计与 LOL「L」标志。样式位于 `internal/httpapi/web/silver.css`，在各功能样式后加载，统一导航、表单、表格、状态、消息预览和玩家明细。

- 银白侧栏，石墨色重点指标；蓝色用于主操作和交互焦点。
- 自然中文字体，数字保留现有三位小数格式。盈利与亏损仍使用明确的状态文字和语义色。
- 现有操作、业务接口、鉴权、幂等和结算逻辑保持原样。页面使用服务端数据，不引入设计预览中的演示统计。
- 玩家明细可直接从侧栏进入。后台支持紧凑导航、窄屏表单与玩家流水卡片。
- `prefers-reduced-motion` 下关闭动态效果，保留键盘焦点。

## 标志来源

`web/league-of-legends.svg` 来自 [Simple Icons 13.21.0](https://cdn.jsdelivr.net/npm/simple-icons@13.21.0/icons/leagueoflegends.svg)，原始路径未经修改，使用单色图形。随程序打包，从同源路径加载，不依赖运行时第三方 CDN，也不放宽 CSP。
