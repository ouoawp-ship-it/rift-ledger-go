# 合并图文消息

消息模板中的图片与其下方连续文字现在合并为一条 Telegram 图文消息，使用 `sendPhoto` 的 `caption` 字段，保留期数等变量以及原有操作按钮。下一张图片开始新消息；图片前的文字仍按原顺序发送。新上传图片默认插到当前文字段落上方，支持继续上下调整顺序。

- 后台即时预览与“校验并预览”都按实际发送分组显示。
- 已保存模板无需重新上传，之后生成的消息自动使用合并逻辑；已入队快照不重写、不补发历史公告。
- Telegram [sendPhoto 文档](https://core.telegram.org/bots/api#sendphoto)规定图注最多 1024 字符。实现按 UTF-16 单位保守计数，变量展开后将超出部分按普通文字继续发送，不丢字、不拆开 Emoji 代理对。多个文字段落之间保留空行。
- 图文消息失败保留 FAILED；结果不明或发送中重启保留 UNKNOWN，供管理员核实，避免自动重复公告。明确未发出和限流仍沿用现有重试机制。旧版纯装饰图片继续使用原有兼容处理。
- 修复读取模板时第一段图片继承默认文字的问题，避免图片在首段时出现“请上传有效图片”。

验证覆盖：变量展开、多图顺序、长文字及 Emoji、键盘按钮、快照幂等、发送成功/拒绝/限流/未知、重启恢复，以及浏览器中图片与图注共用一个消息气泡。线上不主动发送测试公告。
