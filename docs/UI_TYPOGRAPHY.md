# 控制台文字系统

控制台采用苹果中国官网常见的文字层级方向：大标题使用更大的显示字号和半粗字重，说明文字保持较轻、较松的行高，导航和表格文字降低对比度，让操作重点自然落在当前页面和主要按钮上。

- 字体优先使用系统字体：`-apple-system`、`SF Pro Display`、`SF Pro Text`、`PingFang SC`，Windows 环境回退到 `Microsoft YaHei`。
- 页面标题 32px / 600，移动端 28px；区块标题 17px / 600；正文与表单 14px；表格 13px；辅助说明 12px。
- 标题使用轻微负字距，正文保持自然字距，避免中文笔画挤在一起。
- 数字账目继续使用等宽数字字体，确保余额、赔率和期号对齐可读。
- 仅调整视觉层级，不改变业务文字、接口或操作逻辑。
